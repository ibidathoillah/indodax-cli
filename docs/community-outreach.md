# Community Outreach

Use these short messages when sharing the project in developer and crypto communities.

## Reddit

Title: `indodax-cli: Rust CLI and MCP server for Indodax`

Body:

`indodax-cli` is an unofficial Rust command-line tool for Indodax market data, private account data, spot orders, WebSocket streams, paper trading, alerts, and MCP integration for agents. It supports table and JSON output, guarded dangerous operations, and local credential configuration.

Repository: https://github.com/ibidathoillah/indodax-cli

## Telegram or Discord

`indodax-cli` now supports market/account commands, private WebSocket order streams, paper trading, alerts, and an MCP server for agent workflows. Public market commands do not need credentials, and trade/funding tools require explicit acknowledgement.

Repo: https://github.com/ibidathoillah/indodax-cli
